# Zero Trust Architecture and Network Micro-Segmentation

## Core Principles of Zero Trust (NIST SP 800-207)
- **Never Trust, Always Verify**: Perimeter defense alone is insufficient; all requests must be authenticated and authorized regardless of source location.
- **Explicit Verification**: Always authenticate based on all available data points (identity, device health, location, workload context).
- **Least Privilege Access**: Restrict user and service access with Just-In-Time (JIT) and Just-Enough-Access (JEA) policies.
- **Assume Breach**: Minimize blast radius by segmenting networks, encrypting all end-to-end sessions, and analyzing telemetry in real time.
